# Minesweeper Game

A classic Minesweeper game implemented with HTML, CSS, and JavaScript.

## Features

- Three difficulty levels: Beginner, Intermediate, and Expert
- Timer to track your game progress
- Mine counter
- Flag placement with right-click
- Auto-reveal of empty cells

## How to Play

1. Open `index.html` in any modern web browser
2. Select your preferred difficulty level from the dropdown menu
3. Click "New Game" to start

### Game Rules

- Left-click to reveal a cell
- Right-click to place a flag on a suspected mine
- The numbers indicate how many mines are adjacent to that cell
- Reveal all non-mine cells to win the game
- If you click on a mine, the game is over

## Implementation Details

This game is built using:
- HTML5 for structure
- CSS3 for styling
- Vanilla JavaScript for game logic

No frameworks or libraries were used in this implementation.
